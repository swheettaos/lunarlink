# API Reference

Every endpoint LunarLink itself serves, by area, with its parameters, an example and a real answer from a running game
(cut to a couple of items). The [docs site](https://swheettaos.github.io/lunarlink/api.html) has the same as a
searchable page. In the game, `GET /help` and `/help.html` also list the endpoints of any plugin
that adds its own. Each endpoint says what it does and **what it's for**. See [[Using the API]] for the pattern, and [[API Recipes]] for
whole jobs step by step.

Which module serves an area: `LunarLink` is the core; the areas in brackets come from the hot modules
`LunarLink.Api` and `LunarLink.Perf` (see [[How It Works]]).
